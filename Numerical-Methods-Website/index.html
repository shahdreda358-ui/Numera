Quick guide

Root finding

Enter a function using x. For Bisection and False Position, choose an interval [a, b] where the function changes sign. Newton–Raphson uses an initial guess; Secant uses two initial guesses.

Linear systems

Enter the coefficient matrix A one row per line and separate numbers with commas or spaces. Enter vector b in the same order. The initial guess defaults to zero.

Interpolation

Enter matching comma-separated x and y values, then the target x. Newton Forward, Newton Backward, and Stirling require equally spaced x-values; Lagrange does not.

Function syntax

Supported examples include x^3 - 4*x - 9, sin(x), exp(x), sqrt(x), and log(x). Use pi for π.
