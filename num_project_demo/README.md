# Advanced Numerical Methods Calculator — Web Demo

A Streamlit web interface adapted from the original Tkinter Numerical Methods project.

## Run locally

```powershell
uv venv
uv pip install -r requirements.txt
uv run streamlit run app.py
```

## Deploy
1. Upload `app.py`, `requirements.txt`, and this README to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Choose the repository, branch, and `app.py`, then deploy.

The original desktop app remains unchanged; this is a separate web version.
